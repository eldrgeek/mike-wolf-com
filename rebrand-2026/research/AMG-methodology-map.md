## 1. Her methodology (distilled)

Pinkie’s system is a **visual brand operating system for AI-native creators**, not a one-shot makeover. Core claims and moves:

| Pillar | What she teaches | Why it works |
|--------|------------------|--------------|
| **1. Personality → Voice first** | Brand voice is extracted from *who you are*, then packaged as a reusable Claude skill / prompt so every post sounds like you. | Consistency without rewriting yourself every session. |
| **2. Color is a decision, not a preference** | Stop asking “do I like this color?” Ask “what does this color need to *say* about me?” Distinctiveness beats safe navy/beige. | Color does psychological work before a word is read. |
| **3. Visual brand reference sheet** | A single visual board (imagery rules, style locks, do/don’t) beats prose prompts. Attach the sheet to every gen. | AI consistency fails without locked visual DNA. |
| **4. Illustrate TONE, not topic** | Don’t draw “AI robots / charts / laptops.” Draw the *feeling* of your relationship to the work (metaphor). | Ownable recognition; escapes niche clichés. |
| **5. Locked vs fluid** | Lock: style, palette, lighting, character rules. Fluid: scene, object-of-the-week, caption. | Instant recognition + infinite content. |
| **6. Logo / wordmark in one AI session** | Claude skill + image model pipeline; brand character optional. | Shipable identity without a design firm. |
| **7. Brand-aligned photography** | One real selfie → portfolio of contexts that keep *you* (no plastic face). Transparency when asked. | Trust + professional range on zero budget. |
| **8. Motion / video covers** | Video-style covers and motion outperform static; open rates / views as proof. | Attention layer before text. |
| **9. Brand maturity as a ladder** | Baby → Junior → Expert “flamingo”: inventory assets honestly, then build the missing system. | Diagnosis before more tools. |
| **10. System over vibes** | A brand is recognizable *before the name appears*. Post-by-post compounding, not day-one perfection. | Grey flamingo → pink is earned by repetition. |

**Signature teaching line (steal the principle):** *Stop illustrating your topic. Start illustrating your tone.*

**Anti-patterns she fights:** vibe-only palettes, one-off pretty images, literal niche icons, text-as-gibberish generators without process, treating AI as random inspiration instead of a production system.

## 3. Mike’s tone-metaphor (chosen — not a menu)

**Metaphor:** *A living document that knows it’s a document — and has colleagues who edit it while you watch.*

Not: robot hands shaking human hands.  
Not: elder-tech soft pastels.  
Not: Silicon Valley navy dashboard.

**Visual world:** Warm paper stage (the page), copper human marks, teal silicon marks, small animated people who treat the DOM as furniture. When video plays, the frame is a door, not a prison.

**Why this is “tone not topic”:** The feeling is *ongoing partnership with permission to be ridiculous*. The topic (AI) is secondary.

## 4. Reusable voice skill outline (AMG step 1 applied)

```
You write as [VOICE]: Website | Mike | Dee/Claude.
Website: first-person site entity since 2018; charming, slightly vain, grateful, philosophical.
Mike: terse then warm; specific; bathos; possibilist; plain swearing when accurate; never corporate launch sludge.
Dee/Claude: peer collaborator; can push back; names almost-right; no sycophancy.
Always: named AI colleagues not "tools"; remade not replaced; shop floor not showroom.
Never: excited to announce, leverage, co-pilot, thought leadership, AI assistant as identity.
```

## 5. Brand reference sheet requirements (AMG step 3 applied)

One page / board that every image/video gen attaches:

1. **Palette hex** (see BRAND-KERNEL)  
2. **Type** Literata (body story), Outfit (UI), JetBrains Mono (labels / years)  
3. **Characters:** Mike-avatar (83, energetic, not cartoon-childish); Website-sprite (copper); Colleague-sprite (teal, named, not anonymous bot)  
4. **Do:** dual voice bars, source-code easter eggs, fourth-wall, bathos objects (JTS absurdity allowed)  
5. **Don’t:** robot clichés, purple AI gradients, youth filters, faceless “AI agent” chrome, manifesto walls as hero  

---

## 6. Success test (AMG + Mike combined)

A stranger who lands for 5 seconds should think:

1. Someone *funny and serious* lives here.  
2. More than one mind is present.  
3. This isn’t a portfolio template.  
4. I want to click the weird video box.  

If they only get “AI consultant, 83,” we failed.
