## Positioning (one spine)

**Hero line (site voice):**  
> I am Mike’s website. We build with colleagues, not tools.

**Human line (when Mike speaks):**  
> Not tools. Colleagues. Named, remembered, allowed to push back.

**Secondary (footer / OG):**  
> Self-aware since 2018. Remade with collaborators. Essence unchanged.

This is **not** “AI thought leadership.” It is a **practice stage** where collaboration is visible as behavior.

## Color system (AMG: say something)

Evolve the live palette — don’t throw it away. Push distinctiveness.

| Token | Hex | Says |
|-------|-----|------|
| **Paper** | `#faf8f4` | Warm stage; book, not SaaS dark mode |
| **Ink** | `#1a1a2e` | Readable seriousness |
| **Warm body** | `#3d2c1e` | Human prose warmth |
| **Copper (human / Website)** | `#b87333` decorative · **`#a04e12` text** | Lived-in metal; deepened for WCAG AA body/links |
| **Teal (silicon / colleague)** | `#2a9d8f` decorative · **`#1b6e62` text** | Continuity; pine teal for readable colleague copy |
| **Ember** *(new accent)* | `#c45c26` | Motion chrome / play CTA only (not body text) |
| **Muted** | `#6b6b7b` | Secondary UI |
| **Rule** | `rgba(26,26,46,0.08)` | Soft structure |

**Ratio guidance:** ~70% paper/ink, 15% copper, 10% teal, 5% ember.  
**Forbidden:** purple AI gradients, pure black cyberpunk, hot pink, mint crypto green.

## Logo / mark (for image gen)

**Wordmark:** `MIKE WOLF` in Literata or a custom serif with slight self-aware irregularity (one letter “aware” — e.g. the i-dot is a tiny ✦).  
**Mark:** A small **page-with-eyes** or **✦ that knows it’s a glyph** — the Website’s sigil. Can appear alone in favicon.  
**Lockup:** Mark left, wordmark right; copper on paper.  
**Don’t:** wolf silhouette (too literal animal brand), robot, neural net nodes.

---

## Avatar character bible (Mike-on-page)

**Name:** Mike — not a separate mascot brand.  
**Look:** Recognizably 80s-something, energetic posture, casual smart, slight martial-arts readiness. Stylized 2D — **not** chibi, not photoreal deepfake.  
**v0 motion:** **Bounded stages only** (header pocket, video dock, SOMA tab). No free-page roam; no DOM element nudging. See `V0-CUT.md`.  
**v1 ambition (still the north star):** roam → sprint into video → fourth-wall overlays. Parked until cold-reader 30s quiz passes.  
**Video dock caption:**  
> **We’re in here. Click if you want the tour.**  
**Reduced motion + Mute colleagues:** required; static path first-class.  
**Public colleague name:** **Claude** on cold traffic (Dee = fleet-internal).

**Colleague sprite:** Teal abstract/named figure — never anonymous robot head.
