## Locked decisions

### 1. Color (WCAG)
- **Body / link text copper:** `#a04e12` (burnt)  
- **Body / link text teal:** `#1b6e62` (pine)  
- **Decorative / borders / large type only:** original `#b87333` / `#2a9d8f`  
- **Ember** stays `#c45c26` for motion chrome only  

### 2. First 30 seconds (homepage authority)
Only these beats before scroll or tour click:

1. Readable hero: *I am Mike’s website. We build with colleagues, not tools.*  
2. **One** dual-voice exchange (Website copper + Claude teal) including **one real push-back** (not a joke).  
3. Tour dock with caption: *We’re in here. Click if you want the tour.*  
4. Three doors visible: About Mike · Portfolio · Silicon Children  

**Parked until cold-reader quiz passes:** free roam, typo broom, high-five, idle sitcom, card shimmy, ember sprint trails.

### 3. Avatar motion model
- **Bounded stages only** (header pocket + video dock + optional SOMA tab).  
- **Never move functional DOM** (no nudging links/cards that reflow layout).  
- **Mobile ≤640px:** static docked glyphs only.  
- **Mute colleagues** control required (visible, sticky preference in localStorage).  
- Full roam+sprint+overlay chaos = **v1** after quiz.

### 4. Cast hierarchy
- **Host of the page:** The Website (first person).  
- **Public colleague name on cold traffic:** **Claude** (Dee stays fleet-internal / advanced surfaces).  
- Mike avatar is co-star, not action-hero who steals the thesis.

### 5. Push-back must be real
- At least one **static, specific, technical** almost-right correction on home or portfolio (git-diff style or Claude voice block that corrects a claim).  
- Live LLM push-back remains SOMA manager — not the roaming puppet.

### 6. Bathos budget
- Prose project cards: mostly dry competence.  
- Humor: footer, console, JTS universe cards, one home joke max above the fold.

### 7. v0 ship list (build order)
1. Shared `brand.css` tokens (deepened text colors)  
2. Hero + dual voice + push-back block  
3. Tour dock copy + existing video  
4. Mute control + reduced motion static path  
5. Portfolio why-clusters + living bylines  
6. Songs usher + nav parity  
7. Wire portfolio-films Screening Room  

### 8. Explicit non-goals for v0
- Free-roaming avatar across full page  
- Overlay characters exiting video onto DOM  
- Rive/heavy animation runtime  
- New logo replacement of entire identity (mark concepts exist; ship later)

## Cold-reader quiz (day-1 prototype gate)

After 30s, visitor must answer without scrolling back:

1. Does Mike treat AIs as tools or named colleagues?  
2. Who is speaking on this page besides Mike?  
3. What would you click next if curious?

**Pass:** ≥3/5 correct on Q1. Else cut motion/charm, not the hero line.

---

## Why this still honors Mike’s reach idea

The full circus (roam → sprint into box → fourth-wall breakout) remains the **north-star demo** for v1. v0 proves the thesis with **voice, attribution, and tour** so we don’t ship Clippy before we ship colleagues.
